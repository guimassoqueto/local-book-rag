# Data Sharing and Model Output Checklist: OpenAI models for chat and summaries, opt-in

**Purpose**: Test whether the requirements are complete, clear, consistent and measurable where the
feature is riskiest. It sends book text to a second third party, under that party's own terms
(constitution I). It reads a new model family's stream, replies, citations and abstentions (V,
VII). It adds OpenAI's failures to the fallback paths, and it changes shared code that Claude runs
too. That is why `AGENTS.md` makes this checklist a step of the flow. The configuration, the
success criteria, the records and the library are covered too.
**Created**: 2026-11-20
**Feature**: [spec.md](../spec.md), with [plan.md](../plan.md), [research.md](../research.md),
[data-model.md](../data-model.md), [contracts/](../contracts/) and [quickstart.md](../quickstart.md)

**Note**: This custom checklist is generated by the `/speckit-checklist` command based on feature context and requirements.
**Review Ownership**: This checklist is a reviewer-owned requirements-quality review artifact. Mark an item `[x]` only when the reviewer determines the requirements-quality criterion is satisfied.
**Marker Semantics**: `[x]` means the criterion has been reviewed and satisfied for requirements quality. It does not mean implementation work is complete.

**Resolution, 2026-11-20**: the owner asked for the checklist to be resolved. Four items were the
owner's to decide, and the agent took a default for each, marked **[owner default]**: CHK002
(prompt caching accepted, and said), CHK036 (a model the organization can't use is dropped and
recorded), CHK037 (*História*'s saved summaries are named among what recreating the container
deletes) and CHK038 (Anthropic's billing wording is a recorded follow-up). The agent settled the
rest from what the owner had decided before, each with a change to the spec (its "Corrections from
the requirements checklist"), the research, the data model, the contracts or the quickstart, and
each item says which. Uncheck any whose resolution you don't accept.
